# Chih-Chi (Joan) Huang — personal website

Live site: https://joanuser.github.io/personal_website/

A plain static site (HTML, CSS, a little JavaScript). No build step: GitHub Pages serves the files as they are, from the `main` branch root.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home: hero, how I work, selected work, about, field notes, contact |
| `orvp.html` | Case study: ORVP funding-call tool |
| `campusbite.html` | Case study: CampusBite |
| `carelift.html` | Case study: CareLift |
| `catalyst.html` | Case study: Catalyst Labs |
| `notes-saw-it-solved-it.html` | Field note: Saw it, solved it |

## Assets

Images, the CareLift demo video, company logos and the résumé PDF live in `assets/`.
`assets/dc-lite.js` and `assets/morphdom.min.js` power the interactive parts (tabs, flip cards, toggles). Leave them in place.

## Updating

Replace the files with a new version and commit to `main`. The site updates within a couple of minutes.
